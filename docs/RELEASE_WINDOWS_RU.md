# VoiceBridge Windows 0.5.4 — описание релиза (RU)

**Версия:** Windows 10/11 x64 0.5.4. Это не Windows-версия Ubuntu 0.5.6.

**В архиве:** прежний онлайн-установщик `VoiceBridge-Setup-0.5.4-x64.exe`, ZIP исходников, LICENSE, NOTICE, информация о сторонних лицензиях и SHA256SUMS.

**Установка:** полностью распакуйте архив и запустите EXE от обычного пользователя Windows. При установке скачиваются зависимости, а модель Qwen3-ASR выбирается или скачивается отдельно. **Цифровой подписи Authenticode у EXE нет.**

**Ограничения:** в архиве отсутствуют приватные пакеты миграции и отката. Windows EXE оставлен **побайтово без изменений** из ранее проверенной версии; текст внутри старого установщика может говорить о статусе лицензирования до публикации. Действующая лицензия авторского кода указана в приложенных LICENSE и NOTICE. Для онлайн-установки нужен интернет.

**Лицензия:** собственный код VoiceBridge — Apache-2.0; модель и сторонние библиотеки — по своим лицензиям. Автор уже проверял приложение на Windows, повторное живое тестирование в ходе упаковки не выполнялось.
