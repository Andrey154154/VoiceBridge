# VoiceBridge Ubuntu 0.5.6 — описание релиза (RU)

**Версия:** Ubuntu/Debian amd64 0.5.6. Версия для Windows выпускается отдельно под номером 0.5.4.

**В архиве:** `VoiceBridge-Ubuntu-0.5.6-amd64.deb`, `voice_input_bridge-0.5.6-py3-none-any.whl`, `install.sh`, `check.sh`, `repair-input.sh`, `stop_old.py`, ZIP исходников, лицензия Apache-2.0, NOTICE, сторонние уведомления, SHA256SUMS.

**Установка:** полностью распакуйте архив; из обычного пользователя выполните `bash install.sh`, **не** `sudo bash install.sh`. Затем `voice-bridge-desktop`. Возможны скачивание библиотек и отдельная загрузка модели Qwen3-ASR. Весов модели в пакете нет.

**Ограничения:** прежние приватные комплекты миграции и отката не публикуются. Не заменяйте работающую старую установку без отдельной процедуры обновления. Для системного ввода Ubuntu могут понадобиться дополнительные разрешения. В DEB обновлена обезличенная документация; исполняемый код приложения сохранён из проверенного комплекта.

**Лицензия:** собственный код VoiceBridge — Apache-2.0, зависимости и модель — по своим лицензиям. Автор ранее проверял приложение на целевой ОС; дополнительная аппаратная приёмка при сборке публичного архива не выполнялась.
