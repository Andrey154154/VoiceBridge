# Contributing / Как помочь проекту

**English:** Issues and pull requests are welcome. Indicate whether a change applies to Ubuntu 0.5.6, Windows 0.5.4, or both. Keep the version-specific snapshots separate unless a migration is explicitly planned. Never commit credentials, personally identifying machine configurations, model weights, recordings or internal service URLs. By submitting a contribution intentionally for inclusion, you agree it is contributed under Apache-2.0 unless you explicitly state otherwise (see License §5).

**Русский:** Можно сообщать об ошибках и предлагать изменения через Issues и Pull Requests. Указывайте целевую платформу и версию. Не смешивайте два дерева исходников без отдельного решения. Не публикуйте ключи, персональные конфиги, веса моделей, записи звука или адреса закрытых сервисов. Присылаемые для включения в проект изменения рассматриваются по условиям Apache-2.0 (см. раздел 5 лицензии), если не указано иное.
