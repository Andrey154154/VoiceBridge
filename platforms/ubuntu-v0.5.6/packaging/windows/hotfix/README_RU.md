# Офлайн-обновление Voice Bridge до 0.5.4

Поддерживаются активные 0.5.0, 0.5.1, 0.5.2 и 0.5.3. Повторное применение 0.5.4 допустимо.
Полностью распакуйте архив, выйдите из программы через трей, закройте установщики.
Запустите `Apply-Fix.cmd` без администратора. В конце требуется `DONE: VoiceBridge 0.5.4`.
Используется Python из активного `current.ini`, а не случайная папка versions.
Патч обновляет только пакет приложения и вспомогательные скрипты; модель и зависимости
не устанавливаются. На ошибке предварительной проверки выполняется попытка восстановления
точного прежнего wheel из этого архива, а результат восстановления записывается в журнал.

Важно: новый режим по умолчанию — **активное поле в момент завершения распознавания**.
Исходное окно и его дочерний элемент больше не замораживаются на всё время записи/ASR.
Защита на время самой вставки сохранена. Строгое поведение можно выбрать во вкладке
«Проверка вставки» → «Куда вставлять». Смена режима не перезагружает модель.
Нативная приёмка на Windows в среде сборки не выполнялась.
