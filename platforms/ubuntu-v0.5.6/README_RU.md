# VoiceBridge — локальный голосовой ввод

[English](README.md) · **Русский**

**VoiceBridge** — бесплатное приложение для голосового ввода в Ubuntu и Windows. Удерживаешь назначенную кнопку мыши или клавиатуры, говоришь, отпускаешь — приложение распознаёт речь **локальной моделью Qwen3-ASR** и вставляет текст в нужное окно.

Распознавание выполняется на твоём компьютере, без обязательного облачного сервиса. Для первоначальной установки зависимостей и скачивания модели интернет может потребоваться.

## Возможности

- Голосовой ввод по удержанию кнопки мыши или клавиши (например, `F8`).
- Локальное распознавание речи Qwen3-ASR: выбор установленной модели или отдельная загрузка.
- Вставка текста через буфер обмена и системные механизмы ввода.
- Графический интерфейс Qt, пользовательский словарь, настройки текста, управление моделями и диагностика.
- Работа на CPU или совместимой GPU — в зависимости от оборудования и установленных библиотек.

## Установка на Ubuntu

1. Скачай **архив Ubuntu 0.5.6** из GitHub Releases и полностью распакуй его.
2. В распакованной папке выполни от **обычного пользователя**, без `sudo` перед командой:

   ```bash
   bash install.sh
   voice-bridge-desktop
   ```

3. Выбери локальную модель Qwen3-ASR или скачай её через программу.

Установщик сам запросит повышение прав там, где оно необходимо. Не запускай графическое приложение от root. Для диагностики: `bash check.sh` и `voice-bridge-desktop --diagnostics`. В публичный пакет не входят старые пакеты отката; для обновления более ранней установленной версии может потребоваться отдельная процедура. **Не удаляй уже работающую версию только ради перехода на этот выпуск.**

## Установка на Windows

1. Скачай **архив Windows 0.5.4** и распакуй его.
2. Запусти `VoiceBridge-Setup-0.5.4-x64.exe` от обычного пользователя.
3. Установщик при необходимости скачает зависимости Python/AI; затем выбери или загрузи модель распознавания.

EXE **не подписан Authenticode**, а первая установка требует интернет. Публичный архив не включает приватные пакеты миграции и отката для старых версий.

## Исходники и сборка

Требуется Python **3.11+**. В каждой платформенной папке есть `pyproject.toml`, исходники, тесты и скрипты:

```bash
# Ubuntu 0.5.6
cd platforms/ubuntu-v0.5.6
python packaging/build.py

# Windows 0.5.4 (требуется LLVM clang/lld-link)
cd platforms/windows-v0.5.4
python packaging/windows/build_release.py --out /путь/вне/исходников
```

Это разные деревья исходников с собственными номерами версий. Сборка Windows EXE сама по себе не заменяет проверку на настоящей Windows.

## Конфиденциальность

- После скачивания модели распознавание выполняется локально без обязательной облачной ASR-службы.
- При установке библиотек и загрузке моделей используются сторонние интернет-ресурсы.
- В публичный проект не включены веса моделей, записи микрофона, персональные конфиги, приватные ключи и внутренняя инфраструктура.
- Для вставки текста программа использует системные средства ввода и буфер обмена. Проверяй требуемые разрешения и политику приложений, в которые вставляешь текст.
