# Сторонние компоненты и лицензии

**Apache-2.0 относится к нашему собственному коду VoiceBridge.** Эта лицензия не меняет условия использования сторонних библиотек или моделей.

| Компонент | Назначение | Лицензии и условия |
| --- | --- | --- |
| Qwen3-ASR (Qwen) | Локальное распознавание речи | Веса **не включены**. Карточка отдельно скачиваемой модели `Qwen/Qwen3-ASR-1.7B-hf` указывает Apache-2.0: https://huggingface.co/Qwen/Qwen3-ASR-1.7B-hf |
| PySide6 / Qt for Python | GUI | Для community-версий предусмотрены LGPLv3/GPLv3; также существует коммерческая лицензия. См. https://doc.qt.io/qtforpython-6 и https://www.qt.io/development/open-source-lgpl-obligations |
| PyTorch, Transformers, Accelerate, NumPy, SoundDevice, Librosa, pynput, evdev, FastAPI, Uvicorn | Зависимости распознавания, звука, ввода и локального API | Пакеты загружаются из внешних репозиториев. Условия конкретных версий см. в их лицензиях. В публичный архив исходников эти библиотеки не встроены. |
| Python и pip | Базовые компоненты онлайн-установщика Windows | Загружаются с Python.org / PyPI по собственным лицензиям. |

**При распространении сборок** необходимо выполнять применимые лицензионные условия зависимостей, включая уведомления и, где требуется, обязанности LGPL по исходным кодам/перелинковке. Одной лицензии VoiceBridge для сторонних библиотек недостаточно.

Это перечень известных прямых зависимостей, **не** полный SBOM и не юридическое заключение. Веса моделей в состав публикации не входят.
